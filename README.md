# Minecraft AFK Bot

## Teleport by player ID

Use `tp <source-id> <destination-id>` as a normal chat message (without a leading slash).
Example: `tp 1 4` makes the bot run `/tp imiraZdog JASKO_X`.

IDs: 1 = imiraZdog, 2 = Itz_nipun, 3 = pahanZdog, 4 = JASKO_X.
The bot account must have permission to run `/tp`.

## Start

Run `npm install`, then `npm start`. Sensitive password and webhook values have been cleared in this package. Add your own values in `settings.json`; auto-auth is disabled until you enable it after adding the needed password.
